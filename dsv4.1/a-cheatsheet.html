A.2 数字速查

每一个都能用一行算式复现，算式在右。

  • 131,072 B：64 个 KV 头的 MHA，每层每 token。\(2\times64\times512\times2\)。
  • 5.24 MB/token：上一条乘 40 层。\(131{,}072\times40\)。
  • 1024 B：MLA 一个 512 维潜在，fp16。\(512\times2\)。
  • 40.96 GB：1024 B × 40 层 × 1M 上下文。
  • 2541：20 层 SWA 的感受野。\(1+20\times127\)。
  • 640：一层一次读出的条目数。\(512+128\)。
  • 16,384：HSI 候选池上限。\(2048\times8\)。
  • 288 B：主 KV 一条（FP4）。\(512/2+512/16\)。
  • 68 B：Indexer K 一条。\(128/2+128/32\)。
  • 2.5：等效份数 \(\sum1/m\)。\(3\times\tfrac12+1\)。
  • 890 B：每 token 全局 KV。\(720+170\)。
  • 3514.25 B：V4-Flash 的基线。\(21\times163+20\times4.5625\)。
  • 3.95：省下的倍数。\(3514.25/890\)。
  • 50.2%：N=32768 时 CED 的 prefill 比。\(657{,}920/1{,}310{,}720\)。
  • 543.6B：MoE 专家参数总量。\(35.4\text{M}\times384\times40\)。
  • 3.69：\(\alpha=0.8,\gamma=5\) 时投机解码的平均输出长度。\((1-0.8^6)/0.2\)。
  • 602：1008×1008 的视觉 span。\(24\times25+2\)。
  • 994：1344×1344 被打回 1302×1302 后的 span。\(31\times32+2\)。
  • 968：1920×1080 缩到 1708×966 后的 span。\(23\times42+2\)。
  • 5184 / 576：一张 1008² 的 patch 数与视觉 token 数。\(72^2\) 与 \(24^2\)。
  • 4 / 8 / 40：内容、地址、查询的刷新次数（三个时钟域）。

报告引用的前身工作，按本篇出现的顺序：

  • YoCo（You Only Cache Once）—— CED 的来源，arXiv:2405.05254。
  • Cross-Layer Attention / IndexCache / You Only Index Once / HySparse —— 跨层复用 KV 或索引的四条路线，对应第 4.3 节的三种模式。
  • HISA —— 分层索引（块级粗筛 + token 级精筛），HSI 的对照物。
  • PowerAttention —— SWA 感受野随层衰减的实验依据，bounded replay 的取舍靠它。

A.4 术语表

  • MLA（multi-head latent attention）：K、V 由同一个低维潜在向量的上投影得到，缓存里只存潜在向量。
  • SWA（sliding window attention）：只看最近 \(W\) 个位置。
  • CSA2（compressed sparse attention, v2）：窗口 + 稀疏检索 + 跨层共享 KV 与索引的合成块。
  • CED（causal encoder-decoder）：前 20 层编码、后 20 层复用编码器末端隐状态导出的全局 KV。
  • Full / Reindex / Reuse：三种缓存状态——三样都刷新 / 数据命中地址重算 / 全命中只读。
  • HSI（hierarchical sparse indexer）：先按块最大分选块，再在候选池内选位置。
  • bounded replay：Decoder 只重放最后 \(W\) 个位置来近似恢复局部 KV。
  • mHC：多条残差流，混合矩阵用 Sinkhorn 迭代约束为双随机。
  • Engram：n-gram 哈希查表的条件记忆，196B 参数。
  • DSpark：3 层草稿模型 + 并行 5 位 + Markov 头的投机解码。
  • MXFP4：OCP 的 4 bit 格式，E2M1 载荷 + 每 16 通道一个 E4M3 缩放因子。
  • ViT：视觉 Transformer，双向、无因果掩码；这里 32 层、16 头、每头 64 维。
  • span：插入主干的视觉位置总数，含行标记与首尾标记，\(h'(w'+1)+2\)。
  • QAT（quantization-aware training）：前向模拟量化、反向直通梯度，让模型适应低精度缓存。
  • AGU / TLB：地址生成单元与地址翻译缓存；报告用它们类比 Indexer 与 HSI 候选池。

A.5 三问自检

读完报告任意一节，用这三个问题检验自己是不是真的读懂了。

  1. 它动的是三个因子里的哪一个（条目大小 / 条数 / 层数）？如果答不出来，说明还没定位。
  2. 它省了多少字节或多少 FLOP？必须能写出算式，并且分母是同一口径（每 token、每层、还是每会话）。
  3. 它付了什么代价？三种常见代价：精度近似（bounded replay、FP4）、表达力受限（同一份 KV 的 512 维倾斜族）、训练复杂度（HSI 要求训推同构）。
判断方法

三个问题都答得出，这一节才算读完；只答得出第一个，是"知道名字"而不是"理解结构"。
