inferserver 的数学基础

这一页写给这样的读者：本科数学学过，但计算过程已经记不清了。所以不假设你记得导数表、方差公式、矩阵乘法规则；每用一个概念，就在原地定义并推出来。

内容只覆盖这个仓库真正用到的数学：softmax、交叉熵 / KL、RMSNorm、线性层、SiLU / SwiGLU、残差、注意力、RoPE、GQA、KV cache、paged attention 的 online softmax、采样、batching 与浮点误差。每一节末尾都标出对应的 Go 代码。

公式用本地 KaTeX 渲染（assets/katex），断网也能看。整个目录是静态 HTML，直接双击打开即可。

怎么读

  • 第一次：从第 0 节顺序读到第 14 节。每节都先给定义，再给推导，最后给“容易写错的地方”。
  • 配对代码看：读完一节，打开它末尾标出的 Go 文件；公式和代码行基本一一对应。
  • 查公式：附录 A 是一页表格，列出所有公式和它们在仓库里的位置；附录 B 反过来按文件索引。
  • 想快速建立直觉：先读第 1、7、10、11 节，这四节覆盖了推理服务里最核心的数学。

章节

  • 0记号与预备：内积、矩阵、求和、导数

    只定义后面会用到的语言：内积、矩阵乘向量、指数对数、四条求导规则、期望与方差。

  • 1softmax：为什么是指数，为什么先减最大值

    从“证据可加、相对概率只看差值”这个要求解函数方程，推出指数形式；再证明减最大值是恒等变形，并给出 Jacobian。含温度滑块 demo。

  • 2交叉熵、KL 散度、困惑度

    自信息 → 熵 → 交叉熵 → KL，Gibbs 不等式一行证完；困惑度就是损失的指数。

  • 3RMSNorm：从 LayerNorm 推出来

    先验证 LayerNorm 的均值 0 / 方差 1，再说明 RMSNorm 省了什么；尺度不变性与 Jacobian；Qwen3 的 per-head QK-Norm。

  • 4线性层、参数量与计算量

    矩阵乘向量的 FLOP 计数；把 Qwen3-0.6B 的 0.596B 参数、2.22 GiB fp32 常驻内存、每 token 1.19 GFLOP 逐项算出来。

  • 5sigmoid、SiLU 与 SwiGLU

    sigmoid 的对数几率解释与导数；SiLU 求导；SwiGLU 的门控为什么是逐元素乘。

  • 6残差连接与 pre-norm

    为什么残差能把梯度连乘展开成 2^L 条路径；Qwen3 两条残差的准确数据流。

  • 7注意力：点积、缩放、因果掩码

    点积的方差是 d，所以除以 √d；因果掩码为什么必须加在 softmax 之前；输出是 V 的凸组合；prefill 二次、decode 线性。

  • 8RoPE：旋转位置编码为什么是相对的

    旋转矩阵保持长度；证明内积只依赖 n−m；频率的几何级数；HF 的 rotate_half 与劈半配对为什么等价。

  • 9GQA：多个 Q 头共用一个 K/V 头

    h/G 的映射；省的是 KV 内存和 K/V 投影，不是注意力 FLOPs；224 KiB/token 的来历。

  • 10KV cache：自回归分解与增量解码

    链式法则展开；无 cache 是 O(T³)，有 cache 是 O(T²)；三种 KV 实现的取舍与内存账。

  • 11Paged attention 与 online softmax

    块表地址公式；online softmax 的合并为什么数学上恒等；引用计数与写时复制。

  • 12采样：温度、top-k、top-p、逆变换

    温度的两种极限；top-k 等价于子集重归一化；top-p 的自适应截断；逆变换采样为什么按累积概率就对。

  • 13批处理、padding、chunked prefill

    算术强度 B/2 说明 decode 是带宽受限；padding 浪费；chunked prefill 不减少总 FLOPs，优化的是公平性。

  • 14浮点数与误差：为什么容差是 1e-6

    float32 的 epsilon；四类误差来源；怎么用相对误差判断“是舍入还是公式错了”。

  • A附录 A. 公式速查表

    一页表格：每个公式 + 它在仓库里的文件与函数。

  • B附录 B. 数学 ↔ 代码索引

    反过来按代码文件索引数学概念，末尾是整条前向公式链。
