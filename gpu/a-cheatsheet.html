A.2 启动配置

项取值说明
block 大小128–256，且是 32 的倍数上限 1024；尾 warp 不要有空 lane
grid 大小\(\lceil N/\text{block}\rceil\)，或 perSM × SM 数后者配合 grid-stride
动态 shared第三启动参数传字节数超过 48 KB 需 cudaFuncSetAttribute
寄存器约束__launch_bounds__(256, 4)比全局 -maxrregcount 精准
共享内存转置float tile[32][33]+1 消 bank conflict
block 形状dim3(32, 8)二维索引时 x 最快变化

A.4 症状与原因

症状先查什么
比 CPU 还慢传输/启动占比；数据是否常驻显存（0.5、6.1）
只有峰值带宽的 10%–20%跨步访问、AoS、每线程 4 B（2.3）
某个 kernel 慢 8 倍warp 内地址跨 128 B，sector 浪费（2.3）
某个 kernel 慢 32 倍shared 32 路 bank conflict（2.4）
结果随机、偶发错误缺 __syncthreads、数据竞争（3.1、3.6）
挂死发散的 __syncthreads、跨 block 自旋（3.1、3.3）
结果全 0 / 垃圾没拷贝、没初始化、没同步就读取（6.8）
launch failed: invalid configurationblock > 1024、shared > 上限、grid 超限
illegal memory access越界、未对齐的 float4、用错设备指针
第一次慢、后面快warmup 不足、时钟爬升（7.1）
算力利用率只有 10%分支发散、依赖链长、没用 FMA/Tensor Core（1.2、5.5）
占用率上不去寄存器或 shared 太多、block 太小（1.5）

A.5 术语

术语含义
SMStreaming Multiprocessor，GPU 的计算单元，内含多个 warp 调度器
warp32 个 lane，GPU 的调度单位
lanewarp 里的一个执行通道，对应一个“线程”
block线程块，同步与 shared memory 的边界
grid一次 kernel 启动的所有 block
occupancy常驻 warp 数与硬件上限之比
coalescing一个 warp 的地址被合并成尽量少的 32 B sector
bank conflictshared memory 中多个 lane 访问同 bank 的不同地址而串行
halostencil 分块时需要额外加载的邻域边界
roofline用算力和带宽两条斜线给出性能上界的模型
WMMAWarp Matrix Multiply-Accumulate，Tensor Core 的 warp 级接口
TF3219 位浮点（10 位尾数），Tensor Core 的 FP32 替代精度
pinned memory被锁页、可被 DMA 直接访问的主机内存
UVA统一虚拟地址，主机与设备指针在同一地址空间
